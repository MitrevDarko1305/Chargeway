# Chargeway ⚡

A web app that provides comprehensive information for electric vehicle drivers — 
covering both charging stations and detailed vehicle data.

## What it does

- Provides detailed specs and information for specific EV models
- Pulls real charging station data directly from car manufacturer pages
- Explains what each charger type does (AC, DC, CCS, CHAdeMO, etc.)
- Matches charging compatibility based on specific car models
- Helps users understand charging speeds, connector types, and range data

## Tech Stack

- **Backend:** Node.js, Express
- **Templating:** EJS
- **Database:** PostgreSQL
- **Other:** fetchImages.js for media handling

## Getting Started

```bash
npm install
node server.js
```
